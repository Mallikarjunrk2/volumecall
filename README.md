## 🚀 Overview

VolumeCall helps Indian investors analyze stocks with clean visualizations, AI-powered insights, financial statements, peer comparisons, corporate actions, and valuation metrics—all in one place.

Designed to make stock research simple, fast, and accessible.

# ⚙ Installation

```bash
git clone https://github.com/YOUR_USERNAME/volumecall.git

cd volumecall

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env.local`

```env
GOOGLE_API_KEY=

UPSTOX_API_KEY=

UPSTOX_ACCESS_TOKEN=

INDIAN_API_KEY=

NEXT_PUBLIC_LOGO_DEV_PUBLISHABLE_KEY=
```
